# 提交前自检清单（反套话）

逐条检查，任何一项不通过都必须改写后再提交。

## A. 事实性检查

- [ ] 每一条"完成了什么"都能在原料清单中找到对应条目（原料映射表已填）
- [ ] 没有把"计划中 / 进行中"的事写成"已完成"
- [ ] 没有编造数字；没有数据的地方已标注 `[待确认]`
- [ ] 主语准确：我主导的写"我"，团队共同的写"团队"，不抢功不推责

## B. 反套话检查

发现以下任一表述，必须按 `references/quantification-phrases.md` 改写：

- [ ] 无"积极推进 / 大力推动 / 持续优化 / 深入开展"
- [ ] 无"大量 / 很多 / 一些 / 各方面"等无量词
- [ ] 无"取得良好效果 / 反响不错"等无观察者的评价
- [ ] 无"进一步加强 / 再接再厉"等纯表态收尾

## C. 结构检查

- [ ] 事实段篇幅 ≥ 全文 50%
- [ ] 每条价值句都锚定在至少一条事实上（删掉价值句上面的事实，价值句就站不住 → 合格）
- [ ] 计划条目与本期事实有衔接，或标注了新增原因
- [ ] 板块数 ≤ 5，无单条目板块（已并入"其他"）

## D. 读者视角检查

- [ ] 上级只看 30 秒也能抓住 3 个重点（本周完成了什么 / 有什么风险 / 下周做什么）
- [ ] 缩写、项目代号首次出现时有展开或上下文可推断
- [ ] 敏感信息（未公开数据、客户名、人事信息）已按用户要求脱敏或删除

## E. 追溯检查

- [ ] 成稿末尾附有原料映射表
- [ ] 原料清单文件保留在本地，可供追问时出示
